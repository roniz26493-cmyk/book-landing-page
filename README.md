# עמוד הנחיתה — סיפור אחד ביום

עמוד נחיתה לספר **"סיפור אחד ביום"** מאת **רועי סלע** — React + TypeScript
+ Vite, ללא שרת או מסד נתונים.

העיצוב, הפלטה והתוכן מבוססים בפועל על כריכת הספר שסופקה
(`רועי_כריכה_10.9.pdf`). קובץ הכריכה המלא במלוא הרזולוציה שמור ב-
`source-assets/cover-front-original.png` למקרה שיידרש חיתוך/עיבוד נוסף.

## הרצה

```bash
npm install
npm run dev       # שרת פיתוח על http://localhost:5173
npm run build     # build לפרסום (תיקיית dist)
npm run preview   # תצוגה מקומית של ה-build
npm run typecheck # בדיקת טיפוסים בלבד
```

## מה כבר מולא בפועל

- שם הספר, כותרת המשנה, התיאור, המשפט המודגש (pull quote) והציטוט
  הפותח ב-Hero — כולם לקוחים ישירות מגב הכריכה.
- פרטי המחבר (רועי סלע) ותקציר הביוגרפיה — מגב הכריכה.
- מחיר הספר: 82 ₪.
- כריכת הספר הקדמית, חתוכה בקפידה מתוך פריסת הכריכה המלאה (כך שלא
  מוצגת הכריכה האחורית או השדרה), בפורמט JPG + WebP.
- תמונה נוספת באזור "על הספר" — פרט מוגדל מתוך איור הכריכה (ללא טקסט).
- תמונת שיתוף (Open Graph) שנוצרה מהכריכה, `public/og-cover.jpg`.
- פלטת הצבעים — נדגמה בפועל מתוך צבעי הכריכה (ראו "צבעי המותג" למטה).
- אזור "מה מחכה לקוראים" — שלושת חלקי המסע שמצוינים על הכריכה: ילדות,
  התבגרות ובגרות.
- קישור לאתר ההוצאה **ספרי ניב** (www.nivbook.co.il), כפי שמופיע על
  גב הכריכה, כאחת מאפשרויות הרכישה החיצוניות.

## מה עדיין חסר ומסומן כ-placeholder

- **מספר הוואטסאפ של המחבר** — לא הופיע על הכריכה. כל עוד לא יוזן,
  כפתורי הוואטסאפ באתר מוצגים במצב לא-פעיל (ללא קישור שבור).
- **תמונת פורטרט של המחבר** — איור הכריכה הוא יצירה אמנותית סגנונית
  ולא תצלום של רועי סלע, ולכן לא נעשה בו שימוש כתמונת "על המחבר".
  מוצג placeholder עד לקבלת תמונה אמיתית.
- **קישורים לחנויות נוספות** מלבד ספרי ניב (שני שדות ריקים מוכנים).
- **קטעים מתוך תוכן הספר** לאזור "הצצה לספר" — היה זמין רק טקסט הכריכה,
  לא קטעים מתוך הפנים עצמו.
- **תשובת FAQ על משלוחים**, כתובת מייל, ורשתות חברתיות.

כל אלה מסומנים בקוד ב-`[סוגריים מרובעים]` ומופיעים באתר עם תגית
"תוכן זמני" קטנה (ניתן להעלים את כולן בבת אחת — ראו למטה).

## איפה להחליף תוכן

כל התוכן הניתן להחלפה מרוכז בקובץ אחד: **`src/data/bookConfig.ts`**
(מתועד בהערות מפורטות). כשמסיימים להחליף את שאר ה-placeholders,
לשנות בראש הקובץ:

```ts
placeholders: {
  showMarks: false, // היה true
},
```

זה מסתיר בבת אחת את כל תגיות "תוכן זמני" שמופיעות באתר.

### תמונות

נתיבי התמונות ב-`bookConfig.ts` מצביעים לקבצים בתיקיית `public/images/`.
כל תמונה נתמכת בזוג `jpg` + `webp` (האתר טוען את ה-WebP הקל יותר
בדפדפנים תומכים, עם fallback ל-JPG). להחלפת תמונה — לשים את הקובץ החדש
תחת `public/images/` ולעדכן את הנתיב בקונפיג (`book.coverImage` /
`coverImageWebp`, `author.photo`, וכו').

### צבעי המותג

`brand.colors` — כל צבע כתוב בהערה מה תפקידו ומאיפה נגזר. הצבעים
נכתבים אוטומטית כמשתני CSS על העמוד בזמן טעינה — אין צורך לגעת בקבצי
ה-CSS כדי לשנות אותם. שימו לב: הגוונים הפונקציונליים (טרקוטה, sage
כהה וכו') הוכהו מעט ביחס לצבעי הכריכה הגולמיים כדי לעמוד בניגודיות
נגישה (WCAG AA) כשהם משמשים טקסט על רקעי קרם/חול/לבן — זו הסיבה
שהגוונים באתר עמוקים מעט יותר מהצבעים הבהירים שרואים באיור עצמו.

### מספר הוואטסאפ

```ts
whatsapp: {
  phone: '972XXXXXXXXX', // ← להחליף במספר האמיתי: בינלאומי, ספרות בלבד
  message: '...',        // ההודעה המוכנה מראש (כולל שם הספר האמיתי כבר)
  areaNotice: 'הזמנה ישירה זמינה לתושבי השרון בלבד',
}
```

כל עוד `phone` אינו מספר תקין (8–15 ספרות), כל כפתורי הוואטסאפ באתר
(בסרגל הדביק במובייל, ובאזור הרכישה) יוצגו במצב לא-פעיל עם הודעה
שמסבירה שהפרטים בדרך — ולא יובילו לקישור שבור.

### חנויות ואתרי מכירה

```ts
purchase.stores: [
  { id: 'niv', name: 'ספרי ניב', note: 'בית ההוצאה של הספר', url: 'https://www.nivbook.co.il' },
  { id: 'store-2', name: '[שם חנות נוספת]', note: '...', url: '' },
  ...
]
```

להוספת חנות — להוסיף אובייקט למערך. להסרה — למחוק אותו. כל עוד `url`
ריק, הכפתור מוצג כ"בקרוב" ואינו לחיץ.

### SEO

תגיות ה-`<title>`, `description` ו-Open Graph נמצאות בקובץ `index.html`
(לא בקונפיג) — כבר מולאו עם שם הספר, התיאור מהכריכה ותמונת השיתוף
`public/og-cover.jpg`. נשאר לעדכן את כתובת ה-`canonical` / `og:url`
לדומיין האמיתי כשהוא ייקבע. `public/favicon.svg` הוא סמל וקטורי כללי
בגווני המותג — ניתן להחליף בלוגו ייעודי אם יהיה.

## מבנה הפרויקט

```
public/
  favicon.svg             סמל לשונית הדפדפן
  og-cover.jpg             תמונת שיתוף לרשתות חברתיות (מהכריכה)
  images/                  כריכה קדמית + פרט איור (jpg + webp)
source-assets/
  cover-front-original.png  הכריכה הקדמית במלוא הרזולוציה (מקור)
src/
  data/bookConfig.ts       כל התוכן להחלפה — קובץ יחיד
  types/book.ts            טיפוסי ה-TypeScript של הקונפיג
  lib/whatsapp.ts          בניית קישור וואטסאפ בטוחה
  lib/applyBrandColors.ts  כתיבת הפלטה כמשתני CSS
  hooks/                   useReveal (אנימציית גלילה), useScrollPast
  styles/tokens.css        משתני צבע/טיפוגרפיה/מרווחים (fallback לפלטה)
  styles/base.css          reset + כפתורים משותפים
  components/              רכיב לכל אזור בעמוד (Hero, AboutBook, Purchase...)
  components/ui/           רכיבי עזר (Section, Reveal, Icons, BotanicalSprig...)
```

כל רכיב עיקרי מגיע עם קובץ `*.module.css` צמוד (CSS Modules — בלי
התנגשויות שמות). כל הטקסטים מגיעים מ-`bookConfig.ts`, כך שניתן לעדכן
את כל תוכן האתר בלי לגעת ברכיבים עצמם.

## מה עוד שווה לבדוק לפני עלייה לאוויר

- להזין את מספר הוואטסאפ האמיתי (כולל קידומת 972, ללא אפס מוביל).
- להשלים את שאר ה-placeholders (ראו "מה עדיין חסר" למעלה).
- להעביר `placeholders.showMarks` ל-`false`.
- לעדכן `og:url` / `canonical` ב-`index.html` לדומיין האמיתי.
